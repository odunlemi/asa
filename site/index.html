English-to-Yoruba Speech-to-Speech Translation

Àṣà is a real-time speech-to-speech translation system for English and Yoruba. It combines a mobile React Native client, a Convex orchestration backend, and a Modal-hosted FastAPI service for transcription, neural machine translation, and text-to-speech synthesis.

Source code and documentation are available on GitHub. Mobile builds and a technical report will be linked when ready.

Source on GitHub · Downloads · Report

Overview

Àṣà enables end-to-end spoken translation from English to Yoruba. A user records English speech in the mobile app; the system transcribes the audio, translates the text into Yoruba, synthesizes Yoruba speech, and plays it back. Translation text is returned as soon as it is ready, while audio synthesis runs asynchronously to keep response latency low.

Key features

  • End-to-end speech-to-speech pipeline
  • Mobile-first React Native interface with translation history and audio playback
  • Open-weight translation and text-to-speech models
  • Convex actions for coordination and Modal for GPU inference

Pipeline

  1. Speech recording. The mobile app records English audio and uploads it to Convex storage.
  2. Transcription. A Convex action generates a signed URL and sends the audio to AssemblyAI for English transcription.
  3. Translation. The English transcript is translated to Yoruba by Davlan/m2m100_418M-eng-yor-mt.
  4. Synthesis. The Yoruba text is passed to Shinzmann/soro-tts-yor, a VITS-based text-to-speech model, to generate audio.
  5. Playback. The synthesized audio is stored in Convex and played back in the app.

System stack

  • Mobile: React Native, Expo SDK 54, Convex React
  • Backend & infrastructure: Convex, Modal, FastAPI, Uvicorn
  • Machine learning & audio: PyTorch, Hugging Face Transformers, VITS, M2M100, AssemblyAI
  • Training data: NaijaVoices Yoruba speech dataset
  • Typography: Ojuju, Hanken Grotesk
